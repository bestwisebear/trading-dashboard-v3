# 数据刷新流程参考

## ⚠️ 强制校验步骤
每次数据刷新后，**必须**运行校验脚本并通过才能提交：
```bash
cd /tmp/trading-dashboard
python3 scripts/validate_schema.py data/
```
只有输出 `✅ Schema 校验全部通过` 才能 `git add && git commit && git push`。

## 关键字段名规范（HTML ↔ JSON 映射）

### positions.json
- `summary.net_today` — 今日收益（必须）
- `summary.monthly_pnl` — 本月收益金额（必须）
- `summary.today_return` — 语义别名，保留兼容
- `summary.total_pnl_amount` — 语义别名，保留兼容
- `summary.prev_close_assets` — 昨日总资产（计算今日收益用）

### reviews_daily.json
- 顶层键名必须是 `records`（不是 `reviews`）
- 每条记录为扁平结构，必须包含：
  - `date`, `pnl_amount`, `pnl_percent`, `trade_count`, `violation_count`
  - `execution_score`, `discipline_score`
  - `key_decisions` (数组)
  - `operation_analysis` (对象: `good`, `bad`, `improvement`)
  - `planned_executed` (数组), `planned_not_executed` (数组), `unplanned_actions` (数组)
  - `market_review`, `emotion_state`, `tomorrow_focus`

### reviews_weekly.json
- 顶层键名必须是 `records`
- 每条记录必须包含：
  - `week`, `date_range`, `pnl_amount`, `pnl_percent`
  - `trade_count`, `win_rate`, `violation_count`, `execution_score_avg`
  - `best_trade` (对象: `name`, `pnl_percent`, `note`)
  - `worst_trade`, `weekly_reflection`, `key_lessons` (数组)

### reviews_monthly.json
- 顶层键名必须是 `records`
- 每条记录必须包含：
  - `month`, `pnl_amount`, `pnl_percent`
  - `trade_count`, `win_rate`, `max_drawdown_percent`, `sharpe_ratio`
  - `strategy_review` (对象), `monthly_reflection`, `next_month_goals` (数组)

### risk_assessment.json
- `rule_checks` (数组) — 每条包含 `rule`, `passed`, `current_value`
- `level`, `score`, `factors`, `suggestion`

### bottom_signals.json
- `aggregate` (对象: `ratio`, `recommendation`, `recommendation_detail`)
- `history_7d` (数组: `date`, `satisfied_count`, `count`)

### plans.json
- `core_plan` (对象: `action`, `detail`, `conditions`)
- `key_stats` (对象: `win_rate_30d`, `monthly_pnl_percent`, `execution_score`)

### discipline_log.json
- `statistics` — HTML 使用此名（不是 `stats`），两者都要有
- `today_assessment`

### news_impact.json
- `messages[].type` 必须是 `'利好'`/`'利空'`/`'中性'`
- `messages[].impact_level` 必须是数值 2-4

## 数据刷新顺序
1. 更新所有 JSON 数据文件
2. 运行 `python3 scripts/validate_schema.py data/`
3. 同步历史快照 `data/history/YYYY-MM-DD/`
4. 对历史快照中的 positions.json 和 reviews_daily.json 也确保字段正确
5. 再次运行校验脚本
6. git add → commit → push
